# 03 · 阈值校准协议

> **这是移植成败的关键一步。** 四个阈值里三个可以直接沿用,一个(`t_amp`)必须按你的标的和周期重新标定。跳过这步,方法会退化成"所有标的都是 quiet"或"所有标的都是 choppy"。

## 为什么 t_amp 必须校准

`chop_amp` = 围绕趋势线的 RMS 残差,单位是**价格百分比**。它的量级取决于两件事:

1. **标的波动率**——同一周期下,低波动标的(指数、大盘股)的 chop_amp 可能只有高波动标的(小市值、meme)的 1/10;
2. **周期长度**——同一标的,周期越长每根振幅越大,窗口内的 RMS 残差也随之放大。

我们在 71 个标的上的实测(同一周期):`t_amp` 中位数 1.12,范围 **0.156 ~ 3.212**——**最高与最低相差 20 倍**。用一个全局值意味着:低波动标的几乎永远 `quiet`,高波动标的几乎永远 `choppy`/`swing`。

反例(真实踩坑):我们曾把在短周期上标定的 `t_amp = 1.15` 直接用在长周期上,结果 **`quiet` 状态几乎不可达**(实测长周期上 `P(chop_amp < 1.15)` 只有 0~1.5%),等价于把整个"窄幅"状态从状态机里删掉,而且没人发现——直到有人问"为什么某标的开盘日显示窄幅"。

## 校准协议(分位对齐法)

核心思想:**不校准"绝对多大算大",而是校准"这个标的的历史分布里,多大算大"**。

### 步骤

```
输入:
  - 该标的的历史收盘序列(建议 ≥ 2 年,或 ≥ 500 个非重叠窗口;不足则如实披露)
  - 你的生产窗口长度 W(与线上 describe_path 用的 lookback 一致 —— 必须同一个数)
  - 目标分位 p*

1. 把历史切成【非重叠】的 W 根窗口:
       windows = [ y[0:W], y[W:2W], y[2W:3W], ... ]
   (非重叠是为了让样本近似独立;重叠窗会让分位估计过度乐观)

2. 对每个窗口算 chop_amp(用与生产完全相同的函数、相同的 causal 设置)

3. t_amp(该标的) = quantile(chop_amp 样本, p*)

4. 数据不足(窗口数 < 10)的标的:不标定,回退全局默认值,并在输出里标记 pending
```

### p* 怎么定

有两种正当做法,**选一种并冻结**:

| 做法 | 公式 | 适用 |
|---|---|---|
| **A. 继承法(推荐)** | `p* = P(chop_amp < 现行全局阈值)`,在全标的池化样本上算 | 你已有一个能用的全局阈值,想平移到每标的而**不改变整体状态分布** |
| B. 目标占比法 | 直接指定"希望 quiet 占 X%",令 `p* = X%` | 全新系统,没有历史阈值可继承 |

我们用的是 A:池化样本上 `P(chop_amp < 1.15) = 0.298`,于是每个标的取自己分布的 **29.8% 分位**作为 `t_amp`。这样做的性质:

- 每个标的的 `quiet` 占比大致相同(≈30%),不再由波动率大小决定;
- 全局状态分布与校准前一致(平移而非重构),便于对照与灰度切换;
- 是**口径平移**,不是"调参优化"——没有用未来收益去挑阈值,不存在过拟合面。

### 关键约束(每条都有代价)

| 约束 | 原因 |
|---|---|
| **校准窗口长度 = 生产窗口长度** | chop_amp 随窗长系统性变化。用 256 根标定、192 根生产 = 尺子和被测物不同 |
| **非重叠窗口** | 重叠样本高度相关,分位估计的有效样本量被高估 |
| **同一 causal 设置** | causal 与 centered 的残差分布不同 |
| **同一数据清洗口径** | 若生产剔除了休市 bar,校准也必须剔除(见 05 的"死区"讨论) |
| **只校准 amp 轴** | τ/SNR/freq 都是无量纲或已归一的,跨标的稳定;多校准一个轴 = 多一个自由度 = 多一分过拟合风险 |
| **定期重估但不追热** | 建议季度重估;**不要**按近期表现调参 —— 我们用有功效的实验证明过"按近期表现选参数"在本类系统里主动有害 |

### 每标的 vs 分类池化

若某些标的历史太短(新上市),两个选择:

- **回退全局默认**(我们的做法):标记 pending,数据攒够后自动纳入。诚实但那些标的暂时不精确;
- **类内池化**:把同类标的(如"半导体股")的窗口合并算一个类级 `t_amp`。比全局好,比每标的差。

**不推荐**:用极少窗口(< 10)硬算分位——那是噪声不是标定。

## 其余三个阈值

| 阈值 | 默认 | 是否需校准 |
|---|---|---|
| `t_snr = 4.0` | 趋势位移需达震荡振幅的 4 倍 | **一般不需要**。SNR 无量纲,跨标的分布稳定 |
| `t_tau = 0.3` | 方向单调性下限 | **不需要**。τ 有界 [−1,1],语义绝对 |
| `t_freq = 8.2` | 每 100 根穿越 8.2 次 | **一般不需要**(已按 100 根归一)。但若你的周期极端(如 tick 级),值得复核分布 |

若你想验证这三个是否适合你的市场:画出它们在你的历史样本上的分布,检查阈值是否落在合理位置(不在分布的极端尾部)。**若要改,改完必须记录改了什么、为什么、以及改前改后的状态占比对照**——不要静默调参。

## 验收:校准后必查

| 检查 | 期望 | 不通过的含义 |
|---|---|---|
| 五态占比 | 每态都不为 0;没有单一状态 > 70% | 阈值错位,某状态被吞掉 |
| 趋势占比 | 显著低于 50%(我们的经验值:15~35%) | > 50% 说明 t_snr 过松或数据有强趋势偏 |
| quiet 占比 | 接近 p*(若用继承法) | 偏离大 = 校准窗口与生产窗口不一致 |
| 跨标的一致性 | 各标的的 quiet 占比应大致相同 | 差异大 = 有标的的历史样本不足 |
| 与旧口径对照 | 若从全局阈值迁移,列出每个标的的新旧值与状态变化 | 无对照 = 无法判断改动是否合理 |

## 灰度切换建议

从"全局阈值"迁移到"每标的阈值"是**生产语义变更**。建议:

1. 先跑**影子模式**:新旧两套阈值并行计算,只记录不生效,输出双列对照页;
2. 观察至少一个完整周期(含你的市场的所有典型状态);
3. 人工核对若干"新旧判断分歧"的样本,确认新判断更符合肉眼;
4. 再切换,并保留旧口径对照一段时间。

我们的实测:影子跑了 14 天 3243 个周期,分歧稳定在 ~50% 的标的上,且 83% 的分歧方向符合理论预期(旧阈值把安静市误判成噪声市),然后才转正。
