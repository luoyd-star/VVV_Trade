# Regime 光谱识别法 · 可移植规格 v1.0

> 一套**周期无关**的方法:给定任意一段等间隔价格序列(1 分钟、1 小时、日线都行),输出这段路径处在什么"状态"——趋势 / 有序波段 / 高频噪声 / 窄幅——以及它在状态光谱上的连续坐标。
>
> 本目录是**完整规格**:照着做可以 100% 重建,不需要看原实现。

## 这套方法的核心主张

大多数"趋势 vs 震荡"判定用单个指标 + 阈值(ADX>25、价格 vs 均线…),问题是**尺度依赖**:同一段路径在不同窗口下结论相反,而单指标无法表达"震荡有多快"。

本方法换一个思路:

1. **不问"是不是趋势",问"能量分布在哪个尺度"**——把路径做多尺度分解,得到一条能量谱;
2. **方向用路径全体决定,不用端点**——用 Mann-Kendall τ(全点对单调性),而不是"收盘 − 开盘";
3. **趋势 = 位移压过震荡**——用信噪比 SNR = 趋势线净位移 ÷ 围绕趋势线的震荡振幅;
4. **非趋势要细分**——同样是"没趋势",慢摆动(可做波段)和快噪声(应回避)是两件事,用**穿越频率**区分;
5. **状态是光谱上的区域,不是离散标签**——除了硬标签,同时输出五态**隶属度向量**,边界处能看出"正在从 A 滑向 B"。

## 30 秒版本

```
输入: 一段收盘价 y (长度 T, 等间隔)

四个轴:
  τ        = Mann-Kendall 相关系数(y vs 时间序号)     → 方向有多单调, ∈[-1,1]
  chop_amp = 围绕 Theil-Sen 趋势线的 RMS 残差 (%)      → 震荡有多大
  net_pct  = Theil-Sen 趋势线的净位移 (%)              → 方向走了多远
  SNR      = net_pct / chop_amp                        → 趋势压过震荡的程度
  chop_freq= 残差穿越零轴次数 / T × 100                → 震荡有多快

决策树:
  if SNR ≥ 4.0 and |τ| ≥ 0.3:  → trend_up (τ>0) / trend_down (τ<0)
  elif chop_amp ≥ t_amp:       → swing (chop_freq ≤ 8.2) / choppy (chop_freq > 8.2)
  else:                        → quiet

其中 t_amp 必须按标的和周期校准(见 03),其余三个阈值可先用默认值。
```

## 边界声明(诚实条款)

- 本方法是**状态描述**,不是方向预测。它回答"这段路径长什么样",不回答"接下来会涨还是跌"。经我方 24 个预注册实验检验,由此类标签衍生的方向性收益在费后不成立——请把它当**上下文/风控背景**用,不要当信号源。
- "趋势占比"这个数随阈值定义在 ~19%(严格)到 ~79%(宽松)之间变化,**没有客观边界**。这正是需要校准协议(03)的原因。
- 分类是**滞后的**:窗口长度 W 的读数,滞后约 W/2 根。它描述"刚刚过去的这段",不是"此刻这一瞬"。
