## 1. 判断总纲（五条）

**J1 两题一解：扩容为相关性系统服务。** 轮动识别的前置是主题篮子有足够独立成员。⑤实测：现有宇宙**没有合格的"AI 应用篮子"**（MSFT 跨层、AAPL/TSLA 只是端侧候选），而"基建 vs 应用"的脱耦此刻已在数据里（60 天相关：NVDA×MSFT +0.06、MSFT×AAPL +0.04，对照基建块内 NVDA×SOXL +0.71）——缺的不是现象，是**观测成员**。

**J2 扩容瓶颈不在工程在治理。** 实测：稳态周期 10-13s（13 品种）→ 50 品种约 40-50s，限频占用 <7%，库 59MB→约 250MB，新品种冷启动约 2 分钟——工程余量三倍以上。真正要建的是④的治理件：**point-in-time 成员快照（append-only）、观察→核心→退役三池、留存门槛=准入 2/3 的迟滞、经济标的与场馆合约分离**（币安规则允许下架重上；且两份官方文件对 EQUITY 标记价机制口径互相矛盾——场馆风险必须显式建模）。

**J3 相关性系统有三个死亡陷阱，架构必须先天免疫。**
- *估计噪声*：亲测 30d/60d 窗相关差 P90=0.29，与 Fisher-z 理论（T=400 → ±0.098）互洽——朴素滚动相关的"变化"多数是噪声。硬门槛 **T_eff ≥ max(10N, 400)**；日频矩阵在美股永续 3-7 个月历史下不可行 → 矩阵层只在 **1h 共同 RTH 面板**上做（约 6 根/日 × 67-84 交易日即达标），4h/1d 先降维到主题组合。
- *时段错配*：美股永续盘外价格粘滞，与 24/7 加密直接同步会伪造相关与"BTC 领先"假象 → **三面板分立**（加密 24/7 / 美股 RTH / 跨类只取共同 RTH 小时），NYSE 日历从"已知缺口"升格为**阻塞性前置**。
- *方向不可知*：相关矩阵是对称的，结构变化证明不了"资金从基建流向应用"；行业动量主要来自自身自相关而非交叉预测（Pan-Liano-Huang）；量与 ΔOI 不是净流入（OI 多空恒等）。**方向结论必须由三票合成**：剥离市场因子后的残差相对强度（RS）交叉 + 广度确认 + VWAP 量流参与，且在下一个非重叠块复现。

**J4 定位是"证据累积雷达"，不是交易触发器。** 六路一致的暗面证据：Giglio-Kelly-Pruitt（吸收率样本外 R²为负）、Cederburg（103 策略波动门控无系统优势）、Molchanov-Stangl（1,022 个周期轮动策略费后≈随机）、Goldman 四阶段（"基建必然轮到应用"无单向规律）。美股永续历史 7 个月、独立轮动 episode 一只手数得完——本系统按锁箱哲学**先积累证据**，门控生产化有独立闸门（见 X4）。

**J5 与五状态机正交，不做笛卡尔积。** 新增 `corr_state` / `rotation_event` 独立轴，按影子纪律运行（不改单品种判定）；未来若门控，只做仓位乘数 {1, 0.75, 0.5} 且第一阶段乘数恒 1 纯审计。

## 3. 相关性系统四层架构

```
L0 输入层    三面板（加密24/7 | 美股RTH | 跨类共同RTH小时）
             + 时段波动标准化 + Ledoit-Wolf 收缩 + 双速 EWMA（快窗预警/慢窗确认）
L1 全局共振  C+（有符号均值相关）/ AAC / 相关离散度 / λ1‖N + 波动分位 V + 广度 B
             → corr_state ∈ {平静分化, 同步risk-on, 压力, panic_rebound, 轮动候选}
             阈值 = 因果分位数（先验待校准，同 THRESHOLDS 纪律）
L2 主题结构  冻结版本化篮子 → 剥离市场因子的残差矩阵 Frobenius 漂移 + 聚类 ARI
             + beta 对冲残差 RS 排名迁移 + 广度 + VWAP 量流参与
             → rotation_event（三票合成才有方向语义）
L3 门控影子  gate_multiplier ≡ 1 纯审计 → 四臂实验（原系统/无条件缩仓/仅波动/联合）
             样本外稳定胜过 vol-only 才讨论启用
```

**明确不做清单**（文献反证充分）：DCC 当默认（只作挑战者，Adams：滚动窗有时反而更好）；MP 硬切谱（N<50 且厚尾，渐近假设不成立）；MST/PMFG 当触发器（只作解释层）；RRG 当信号（可视化工具，无样本外验证）；量/ΔOI 当净流入；逐边显著性检验（190-1225 条边的多重比较灾难，必须 global-first + 块 bootstrap）；未过四臂闸门直接门控。

## 4. "AI 基建 → AI 应用"这个具体问题的诚实答案

系统建成后能做到的：**当轮动真发生时，雷达会亮**——应用篮子残差 RS 上穿、广度扩散、基建-应用块间残差相关下降、VWAP 量流迁移，四个证据在面板一屏可见，且每个证据带因果分位与样本量标注。
做不到的（现在）：预测轮动何时发生；把"雷达亮了"直接当买卖信号（独立 episode 太少，任何显著性都撑不住多重检验）。
2025 年 DeepSeek 时刻的教训（⑤实证）：硬件→软件的轮动叙事三个月内反转——雷达的价值恰恰是**在叙事喧嚣时给出"证据到底几票"的冷读数**。
