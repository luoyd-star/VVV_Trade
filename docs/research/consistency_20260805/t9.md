# 路线9：术语与命名口径
同一概念多个名字/同一名字多个概念：
1. 时间：ts 语义（开盘时刻）在所有表是否统一；"ET/美东/纽约时间"、"UTC"、"JST"
   在注释与文案里的使用是否规范；fetched_at/captured_at/snapped_at/known_at/available_at
   各表的"观测时刻"列命名是否一致、语义有无重叠；
2. 波动率名词：iv30/IV30/结算IV/个股IV/DVOL/近端IV/IV3/xopt 在代码变量、payload 键、
   前端文案、Hermes 文案四层的对应关系是否有断裂或混用；
3. 状态名：五状态的中英文（squeeze/低波动挤压 等）在 classify、面板、Hermes、文档是否一致；
4. source 值域：'moomoo'/'binance_futures'/'deribit'/'cboe'… 大小写与拼写在所有表是否统一；
5. 品种符号：XXX-USDT 后缀约定的例外（ref_daily 的 series 名、vol_proxy 的 US.GLD）是否有文档。
