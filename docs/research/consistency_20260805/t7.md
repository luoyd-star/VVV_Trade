# 路线7：前端死代码（web/）
web/index.html + app.js + style.css（.bak 三件已知，不必报）：
1. app.js 里定义后零调用的函数、零读取的变量、注册后不可能触发的事件分支；
2. style.css 里零使用的类选择器/id 选择器（对照 index.html 与 app.js 动态拼的 className）；
3. index.html 里零引用的 DOM id（app.js 从不 getElementById 且 css 不选中）；
4. app.js 从服务端 payload 读取但后端已不再发送的字段（对照 dashboard.py 各 payload 构造）；
5. 后端发送但前端从不读取的 payload 字段（反向）。
动态拼接的类名（模板字符串里的 ${...}）要人工追，别机械 grep 误报。
