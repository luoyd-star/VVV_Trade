# 路线6：Python 死代码
用 grep/静态阅读找：
1. 定义后零调用的函数/方法/类（排除测试专用与 __main__ 入口；main.py 与 scripts/ 的入口函数除外）；
2. 零引用的模块级常量（已知 DEFAULT_SOURCES 与 features/__init__.__all__，找新的）；
3. 不可达分支（条件恒真/恒假、早 return 后的代码、被上层判断短路掉的 elif）；
4. 未使用的 import；
5. 参数从未被任何调用方传非默认值、且函数体内该参数只有一种走向的（潜在可删参数）；
6. 整个文件级：main.py / vvvhermes.py / scripts/ 下每个脚本还有没有存在意义（被谁调、多久没动）。
每条给 grep 命令与输出。注意排除动态调用（getattr/字符串拼接）误报——查过再下结论。
