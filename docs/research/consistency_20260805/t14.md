# 路线14：端到端对拍——同一个数字的所有出口
挑 10 个关键数字，从库出发追到每个出口（面板 payload、前端渲染、Hermes 文本、
collector 日志、文档），验证所有出口同口径同值（活体数字允许时点差，口径必须同）：
1. BTC 的 DVOL 当前值与分位；2. NVDA 的结算 IV 与条件分位；3. BTC 近端 IV 与 tenor；
4. 某美股的 RV30（1d ATR? 还是收益率年化? 各出口算法一致吗）；5. RV3 的 72×1h 年化；
6. VRP=IV−HV 的 HV 是哪个窗、与 RV30 什么关系，文案是否混用；7. 期限结构 9D/30D 比值；
8. put/call 比值；9. OI 分位；10. margin（边界距离）。
每个数字给出：库内源头 → 计算函数 → payload 键 → 前端文案/Hermes 文案 的完整链条，
标出链条上任何口径断裂或文案误导。
