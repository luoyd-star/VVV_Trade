## 自查盲区

- 未联网核验各交易所端点是否契约上保证永远返回形成中末行；第 4 条已证明公共函数存在条件性误删，但未声称当前生产源已经发生该损失。
- 死代码证明覆盖仓库内 Python 静态调用；无法排除仓库外个人脚本、动态 `getattr` 或通用 SQL 手工查询。
- 本路线未继续展开 CSS/DOM 和数据库列级零引用，它们不属于本次六项重复实现主轴。
