# 主题C4：块级/网络级脱耦识别

## 一、文献地图

**共识——社区识别。** 相关矩阵不能直接套普通加权网络的 modularity null；市场共同模态会把资产压进大社区，正确做法是过滤噪声与市场模态，再在 correlation-specific modularity 矩阵上运行 Louvain/谱法。【已核实】[MacMahon–Garlaschelli, PRX 2015](https://doi.org/10.1103/PhysRevX.5.021006)。Louvain 的随机种子和近最优解退化会产生“算法迁移”，因此每窗须多种子、共分配矩阵和共识分区。【已核实】[Lancichinetti–Fortunato 2012](https://doi.org/10.1038/srep00336)。跨窗相似度以 chance-corrected ARI、AMI 为主；普通 NMI 在节点少、簇多时有上偏，只宜旁报。【已核实】[Vinh 等 2010](https://jmlr.org/papers/v11/vinh10a.html)。多层时间 modularity 的层间权重本身就在“当窗结构—时间持久性”间取舍，故其平滑稳定性不是独立证据。【已核实】[Bazzi 等 2016](https://doi.org/10.1137/15M1009615)。

**共识——特征子空间。** 令去市场后的 sector 子空间 \(U_t=[u_{2,t},…,u_{k,t}]\)，对 \(U_s^\top U_t\) 做 SVD，奇异值为 \(\cos\theta_j\)；可取  
\[
d_{\rm sub}=\sqrt{\operatorname{mean}(\sin^2\theta_j)} .
\]
它不受特征向量翻号、交换和子空间内部旋转影响。Davis–Kahan 表明可识别性取决于边界 eigengap  
\[
\delta=\min(\lambda_1-\lambda_2,\lambda_k-\lambda_{k+1});
\]
角度大而 gap 小，只能判“不可辨识”，不能判结构断裂。【已核实】[Yu–Wang–Samworth 2015](https://discovery.ucl.ac.uk/id/eprint/10055409/)。金融实证进一步发现，原始市场状态常主要是在聚类平均相关/第一特征值；扣除 PC1 后会得到完全不同、较持久的结构。【已核实】[Heckens–Krause–Guhr 2020](https://arxiv.org/abs/2004.12336)。

**争议——Münnix 市场状态与前兆。** 2012 年的 S&P 结果为8态，但状态数由停止阈值决定，作者明确指出改变阈值或观察期会继续拆分/合并。【已核实】[Münnix 等 2012](https://www.nature.com/articles/srep00644)。后续用 PAM、power-map、MDS/k-means 得到4—7态不等；较稳健的是“低—中—高相关准稳态”，不是固定状态数。2018 年复现了高自转移、主要相邻转移，但美国“前兆态→危机态”仅5.8%，对比危机态基准占比4.1%，且窗口重叠50%；后续逐日滚动重叠达95%，会机械制造黏性。【已核实】[Pharasi 等 2018](https://arxiv.org/abs/1809.00885)、[后续版本](https://arxiv.org/abs/2011.05984)。更重要的反证是：去市场模态方法在雷曼前看到变化，却未能预警 dot-com。【已核实】[Heckens–Guhr 2022](https://arxiv.org/abs/2107.09048)。因此“状态描述”较可信，“危机预测”仍属探索性。

**块内/块间先例。** correlation-specific modularity 本质就是“块内超额相关减去 null”；另有金融网络研究直接把社区内、社区间连通性及其关系作为系统风险指标。【已核实】[Entropy 2022](https://doi.org/10.3390/e24071005)。但后者使用阈值网络，不能直接移植其阈值或比例。

## 二、对 VVV_Trade 的操作化启示

建议不新增第四套架构，而在现有三面板、Ledoit–Wolf、双速 EWMA 后增加五组最小统计量：

1. **市场模态**：\(m=\lambda_1/N\) 及 \(u_1\) 方向变化。
2. **全局残差变化**：\(R=C-\lambda_1u_1u_1^\top\)，以  
   \(T_G=\|R^{fast}-R^{slow}\|_F/\|R^{slow}\|_F\) 作 omnibus。注意 \(R\) 对角不再为1，应称残差亲和矩阵。
3. **固定主题直读量**：对主题块 \(b\)，计算块内 \(a_b\)、块外 \(e_b\)，以 \(D_b=a_b-e_b\) 为主；仅当 \(a_b>\epsilon\) 时旁报 \(r_b=e_b/a_b\)。\(e_b↓、a_b\) 稳定是“对外脱耦”；\(a_b↓\) 且迁移增加是“内部瓦解”。
4. **社区稳定**：同窗多种子共识置信度；快—慢及逐窗 ARI/AMI/NMI；行归一化成员迁移矩阵。ARI/AMI无需对齐标签，迁移矩阵才用最大重叠匹配并保留 split/merge。
5. **残差子空间**：\(d_{\rm sub}\)、最大 principal angle 与 \(\delta\)；训练期固定 \(k\)，无稳定 eigengap 就输出 NA。

**显著性协议：global-first。** 先对同步的 \(N\) 维收益行做 moving/stationary block bootstrap，复制原窗口重叠、双速权重、缺失模式、收缩和完整聚类流程；区块长度只在训练集选，并做半倍/双倍敏感性。【已核实】[Politis–Romano](https://www.tandfonline.com/doi/abs/10.1080/01621459.1994.10476870)。第一关检验 \(T_G\)；只有全局拒绝稳定结构 null，才检验各 \(D_b\)、迁移和块级 modularity，并以 bootstrap max-stat/step-down 控制多块、多窗错误率。主题解释再做保持块大小的资产标签置换。子空间另加“固定 eigenvectors、允许 eigenvalues/波动变化”的 null，避免把 PC1 强弱变化误判为旋转。

判定分四类：仅 \(m\) 变为全局再耦合；\(D_b\) 变而 ARI、\(d_{\rm sub}\) 稳定为强度型脱耦；\(D_b\)、迁移/ARI、且有 gap 支持的 \(d_{\rm sub}\) 同变，才称拓扑重构；角度未超 bootstrap 或 gap 不足则为不确定。

**预测实验。** 所有 \(k\)、分辨率、共识阈值和状态中心只在训练期确定；未来矩阵投向冻结中心，距离过远允许“未知态”，禁止全样本重聚类。用上述量预测未来窗的有序耦合状态或 \(D_b\) 变化，比较“状态延续”“仅平均相关/PC1”“慢 EWMA”三基线，以 CRPS/Brier、校准和误报率进锁箱。当前数据只能先验证**测量可靠性**：1h RTH/共同RTH在快慢两端均满足 \(T_{\rm eff}\ge400\) 后可做；美股4h/1d历史不足；加密1d长度足但 \(N=4\)，不适合自由社区检测。稀有状态预测须继续积累或回填历史。

## 三、反方与陷阱

滚动窗重叠会同时抬高 ARI 和自转移率；全局 ARI 可掩盖一个小主题崩解；硬阈值会把轻微估计误差放大成大量边翻转；比例在块内相关接近零或变号时失效；动态 PC1 剥离可能吸收真正的主题变化，而不剥离又会被市场模式支配，因此 raw/residual 必须双报。2025 年中国市场研究虽报告约96%的 precision/recall，却随机五折、复制正样本26次且无独立测试集，作者也承认需更严格回测，不能视为锁箱复验。【已核实】[Frontiers 2025](https://www.frontiersin.org/journals/physics/articles/10.3389/fphy.2025.1647667/full)。最后，相关矩阵对称：上述指标预测的是状态概率，不提供冲击方向或因果传播方向。
