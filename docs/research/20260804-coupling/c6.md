# 主题C6：耦合状态机的判定工程

## 一、文献地图

**共识。** 过程报警早已采用“阈值＋deadband＋on/off-delay”：双阈值提供迟滞，连续确认抑制瞬时越界，状态锁存才是真正的最短驻留【已核实】([ISA](https://www.isa.org/intech-home/2019/january-february/features/applying-alarm-management))。Adnan–Izadi–Chen进一步用马尔可夫过程联合计算假报警、漏报和期望检测延迟，证明去抖必然以延迟为代价【已核实】([Journal of Process Control](https://doi.org/10.1016/j.jprocont.2011.06.019))。

金融中也有先例：Lunde–Timmermann以不同涨跌阈值划分牛熊状态，小反向波动不立即翻转【已核实】([论文](https://doi.org/10.1198/073500104000000136))；Pagan–Sossounov加入最短阶段/周期限制【已核实】([论文](https://doi.org/10.1002/jae.664))。但后者包含前后观察窗，属于事后定年，不能直接用于实时状态。

相关监控方面，已有 Fisher-z EWMA 直接监测相关系数的工作【已核实】([论文页](https://scholar.kyobobook.co.kr/article/detail/4040012431550))；Hawkins–Maboudou-Tchao 的 MEWMC 监测整个协方差矩阵【已核实】([Technometrics](https://doi.org/10.1198/004017008000000163))。Li–Li则对允许时间依赖、非高斯的高维协方差在线变化给出 ARL 与检测延迟关系【已核实】([JMLR](https://jmlr.org/beta/papers/v24/20-1101.html))。

**ARL口径。** 令 \(T\) 为完整状态机首次错误进入 `decoupled` 的时间，则 \(ARL_0=E_\infty T\)；变化后应报告条件检测延迟，而非某个中间统计量的逐点显著性。ARL均值不足够：在无记忆基准下，即使 \(ARL_0=500\)，100次更新内至少一次误报仍约18%。因此还需报告 \(P_0(T\le H)\)、运行长度中位数/P90，以及零状态、稳态、最坏状态延迟【已核实】([NIST](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc3231.htm))。

**三类阈值。**

- 绝对阈值：效应大小可解释、跨期可审计，但不同 pair/频率的误报率不一致。
- 因果分位数：适应资产异质性，但固定尾分位会机械地产生事件；持续异常还会污染窗口，把结构断裂重新“正常化”。
- surrogate：能回答“是否超出明确零模型”，但结果高度依赖零模型。状态检测应检验“相关结构稳定”，而非简单检验 \(\rho=0\)。替代数据方法本身也有平稳性、零模型解释等限制【已核实】([Schreiber–Schmitz综述](https://doi.org/10.1016/S0167-2789(00)00043-9))。

**从业者结论：**进入事件应同时满足“绝对效应量＋因果极端度＋surrogate/ARL门槛”；退出采用较宽松门槛形成迟滞。阈值在活动 episode 内冻结。

## 二、对 VVV_Trade 的操作化启示

令新观测权重为 \(\alpha\)，则 EWMA \(T_{\rm eff}=(2-\alpha)/\alpha\)。初始取

\[
T_F=\max(10N,400),\quad T_S=2T_F,\quad
\alpha=2/(T_{\rm eff}+1).
\]

数据不足时输出 `INSUFFICIENT`，不得缩窗冒充有效估计。

对合格 pair，令参考符号 \(s=\operatorname{sign}(\rho^S)\)，并定义

\[
x_t=s\,\operatorname{atanh}(\rho^F_t).
\]

只对 \(|\rho^S|\ge0.25\)、参考期同号率≥80%、覆盖率≥95%的 pair赋予四个语义状态；弱相关 pair 是“不适用”，不是“已脱耦”。状态开始时冻结锚点 \(z^A\)，以

\[
d_t=\frac{s(z^A-z^F_t)}{\sigma_{d,0}}
\]

表示相对基线的标准化脱耦幅度。

| 参数 | Pair 初始先验 | 块级初始先验与校准 |
|---|---|---|
| 因果水平阈值 | \(L=q_{10\%}(x)\)，\(H=q_{30\%}(x)\) | 对块内 \(x\) 中位数同样计算 |
| 绝对效应门 | \(\delta^*=Q_{90,\rm null}|\,\rho^A-\rho^F\,|\)；60d版本先用0.29 | 由整块联合 surrogate 估计 |
| `coupled→decoupling` | \(x<H,d\ge2,\Delta\rho\ge\delta^*\)，连续2 bar | 标准化块跌幅≥1.5、报警 breadth≥30%，连续2 bar |
| `decoupling→decoupled` | \(x\le L\)，连续3 bar | breadth≥40%，连续2 bar |
| `decoupled→recoupling` | \(x>L\)，且 \(d\) 较本 episode 峰值回落≥0.75，连续2 bar | 恢复 breadth≥30% |
| `recoupling→coupled` | \(x\ge H,d\le0.75\)，连续3 bar | 恶化 breadth≤20%，连续3 bar |
| 驻留/复发 | `decoupled`至少5 bar；其余至少2 bar | 至少3 bar |
| 技术超时 | 活动期超过 \(2T_F\) 转 `REBASE_PENDING`，不得自动洗成 coupled | 人工/锁箱规则重建基线 |
| 有效块 | — | ≥4个资产且≥70% pair有效；共享资产造成的依赖不得按独立 pair 计数 |

块分数采用合格 pair 的中位数，并以 `decoupling/decoupled` pair占比作 breadth；首版不把最大特征值、平均相关和 breadth 加权成一个可调综合分，避免过拟合。

**校准实验。** 对整条多资产收益向量做 stationary block bootstrap，而非逐列重采样；每条路径重跑标准化、Ledoit–Wolf、双速 EWMA 和完整状态机。初始至少20,000条路径，按一个 panel-year 的 \(H\) 校准：

- 每个 pair 的 \(P_0(T_D\le H)\le5\%\)，同时对横截面候选做 FDR 10%；
- 整个 panel 任一块错误进入 `decoupled` 的概率≤5%；
- 注入持续 \(\Delta\rho=\{0.15,0.29,0.40\}\)，对可检测档要求 \(P(\text{delay}\le0.25T_F)\ge80\%\)。

报告完整运行长度分布；连续 \(k\) 个重叠 EWMA 窗绝不能写成 \(\alpha^k\)。

**与现有系统接口。** 不与现有5状态做 \(5\times4\) 笛卡尔积。追加字段：

`pair_state, block_state, valid, score, null_p, state_age, breadth, anchor_id, threshold_version, episode_id`。

解释上：

- pair脱耦、块耦合＝特异性断裂；
- pair与块均脱耦＝系统性断裂；
- pair耦合、块脱耦＝相对韧性。

状态只作为 challenger 特征/风控门，不直接产生方向交易。未来连续相关或冻结对冲误差用 CRPS；四状态转移概率用多类 Brier，而非强行把循环状态排序。

数据上，加密4h/1d可做首轮；美股RTH数月的1h仅够 warm-up/影子验证，4h与1d应保持 `INSUFFICIENT`。未来窗可预注册为1h `{1,6,24}`、4h `{1,6,30}`、1d `{1,5,20}` 个 eligible bars。

## 三、反方与陷阱

第一，相关变化可能只是波动条件化伪象。Forbes–Rigobon证明异方差会偏置危机前后相关比较【已核实】([Journal of Finance](https://onlinelibrary.wiley.com/doi/10.1111/0022-1082.00494))；Corsetti等又指出其修正依赖过强的特异冲击方差假设，得到部分传染证据【已核实】([论文](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=1263402))。故必须同时保存原始、波动标准化及因子残差相关，结论标为“争议”。

第二，事件由极端相关路径内生定义；事件后相关回升可能只是均值回归。主事件取首次确认进入 `decoupled` 的 \(t_0\)，结果严格使用 \(t_0+1:t_0+h\) 新数据，禁止使用仍含事件前样本的长滚动相关。

正确对照是 risk-set matching：在同一 \(t_0\) 从尚未进入 episode 的 pair中，按 panel、现有5状态、市场及两腿波动分位、流动性、基准相关、beta、session匹配；不得事后删除未来也会触发的 control【已核实】([Balanced Risk Set Matching](https://faculty.wharton.upenn.edu/wp-content/uploads/2012/04/Balanced.pdf))。同一 pair每个 episode只取首次 onset；共享资产或重叠未来窗组成一个 inference block，每块总权重为1。匹配仅支持条件预测比较，不能宣称脱耦的因果效应。

第三，账本必须在每根 bar记录所有 at-risk pair-time 的因果特征、事件标记、基准/状态模型预测CDF；结果成熟后再 append-only 写入未来结果和CRPS。否则事后挑 control 会产生隐性未来泄露。锁箱前冻结匹配、horizon、placebo、依赖块和主终点。CRPS的严格 proper 性质有正式依据【已核实】([Gneiting–Raftery](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf))。

最后，相关对称；任何“谁带动谁”“脱耦后做多A空B”的表述都越过了统计量能支持的范围。

## 四、优先级

1. **P0，中改动：**实现因果 pair FSM、技术态和 append-only 账本；加密可验证，美股1h只影子运行。
2. **P1，中高改动：**联合 surrogate/ARL/注入漂移平台；这是上线块级报警前的硬门槛。
3. **P2，高改动：**risk-set事件研究及锁箱预测比较。至少积累30个独立 inference blocks、且锁箱 \(\Delta CRPS<0\)，才允许状态进入现有5状态机的正式决策路径；此前只作诊断输出。
