# 主题C2：相关性本身可预测吗

## 一、文献地图

**结论先行：相关性水平具有有限、状态依赖的可预测性；精确脱耦时点没有稳健证据。**以下关键结论均为【已核实】，无依赖记忆的文献断言。

**共识：持续性与均值回复并存。** HAR-DRD 将协方差分解为 \(S_t=D_tR_tD_t\)，以日、周、月相关预测 \(R_t\)。Bollerslev、Patton、Quaedvlieg 对10只DJIA股票估得相关项权重 \(0.049,0.159,0.560\)，总和0.768：冲击消退很慢，但仍向长期相关矩阵回复；月度信息明显强于昨日值。【已核实：[2018原文](https://public.econ.duke.edu/~ap172/BPQ_MV_HARQ_2018_JoE.pdf)】较新的27股研究估得权重和0.888；加入相关对之间的网络信息，样本外协方差损失再降约1.8%–2.5%。【已核实：[Graph-HAR](https://academic.oup.com/jfec/article/23/2/nbae026/7889003)】因此“高相关后均值回复”的严格含义只是：在长期中枢稳定的条件下，期望变化偏负；它不提供反转日期，更不预测收益方向。

**DCC/cDCC：能预测，但没有稳定冠军。** DCC以少量参数递推标准化残差的条件相关；Aielli证明原DCC的大系统估计可能不一致并提出cDCC，但这是估计性质，不等于样本外必胜。【已核实：[Engle 2002](https://doi.org/10.1198/073500102288618487)、[Aielli 2013](https://doi.org/10.1080/07350015.2013.771027)】Manner–Reznikova发现，动态模型在G5周频预测似然上能胜常相关CCC，但欧洲日频没有模型系统性胜CCC，组合经济损失更难胜。【已核实：[原文](https://www.econstor.eu/bitstream/10419/45359/1/656643420.pdf)】89只美股比较中，DCC主要在危机期优于CCC；cDCC并未稳定优于DCC，且模型排名会随实现协方差代理和损失函数翻转。【已核实：[Caporin–McAleer](https://repec.canterbury.ac.nz/cbt/econwp/1206.pdf)】一次性跳跃还会污染普通cDCC数周，稳健cDCC才在危机期占优。【已核实：[Boudt等](https://www.riskresearch.org/files/DanielssonBoudtLaurent2013.pdf)】

**简单EWMA经常不输。** 长记忆EWMA在不同维度、相关水平和期限上胜过GARCH-DCC等模型。【已核实：[Harris–Nguyen](https://research-information.bris.ac.uk/en/publications/long-memory-conditional-volatility-and-asset-allocation/)】最新100只美股、2002–2023研究也显示，日/周频EWMA无法被HAR-DRD等复杂高频模型持续击败；计入换手成本后优势更强。【已核实：[Romero–Opschoor 2026](https://doi.org/10.1002/jae.70053)】这直接支持VVV保留双速EWMA为强基准。

**隐含相关有增量信息，但不是无偏物理预测。** 旧ICJ/JCJ/KCJ是按“一月到期年份”轮换的代码，不是固定期限；2021年停发后由3个月恒定期限COR3M替代。两者均由SPX及最大50只成分股期权的隐含方差反解加权等相关，并非普通两两相关均值。【已核实：[旧方法](https://cdn.cboe.com/resources/indices/documents/impliedcorrelationindicator.pdf)、[COR3M白皮书](https://cdn.cboe.com/resources/indices/documents/Implied_Correlation-WhitePaper-v1.0.5.pdf)】早期DJIA研究发现隐含相关虽有偏，却具有高解释力和历史相关之外的信息；外汇期权上也曾显著胜历史、RiskMetrics和GARCH预测。【已核实：[Skintzi–Refenes](https://ideas.repec.org/a/wly/jfutmk/v25y2005i2p171-197.html)、[Campa–Chang](https://doi.org/10.1016/S0261-5606(98)00031-X)】但期权给出的是风险中性 \(E^Q\rho\)，通常高于物理测度 \(E^P\rho\)：若定义CRP为 \(E^Q\rho-E^P\rho\)，经验上为正；这正是相关保险价格，不能直接当无偏预测。【已核实：[Driessen等](https://doi.org/10.1111/j.1540-6261.2009.01467.x)】COR3M自身历史短，尚不能把上述同类证据等同于“COR3M已充分样本外验证”。

**转折点：正面证据只到状态概率。** 非高斯Markov-switching相关模型能改善样本外风险、密度及配置结果。【已核实：[Paolella等](https://doi.org/10.1016/j.jeconom.2019.07.002)】但它输出的是未来状态概率或hazard；固定转移概率主要外推当前状态的持续性。在线变点算法则是在变化发生后权衡误报与检测延迟。【已核实：[Maillard 2019](https://proceedings.mlr.press/v98/maillard19a.html)】本次检索未发现跨周期、严格实时样本外同时报告提前量、误报率和日期误差，并能稳定提前报出“耦合→脱耦”具体日期的研究。

## 二、对 VVV_Trade 的操作化启示

**可作为预测输出：**

- Pair目标定义为严格未来窗  
  \[
  \rho^{F}_{ij,t,h}=\operatorname{Corr}(r_{i,t+1:t+h},r_{j,t+1:t+h}),
  \]
  建模用 \(z=\operatorname{atanh}\rho\)。输出 \(F_{ij,t,h}\) 的完整分布，而非单一“涨/跌相关”判断。
- 块级主目标预注册为固定权重的平均Fisher-\(z\)；第一特征值占比作为副目标。两者通常比单pair噪声小。
- 输出“未来 \(h\) 内处于五状态的概率”。连续相关用CRPS；从 \(z\) 分布采样、经 \(\tanh\) 还原后在原始相关尺度评分。五个有序状态用RPS（离散CRPS）；“发生脱耦”事件另报Brier、PR-AUC、校准曲线和提前量。

**只能nowcast：** 当前收缩相关矩阵、当前耦合状态及变点警报。具体脱耦日期、因果方向、跨市场谁领先谁，不进入正式预测产品。

**最小实验：** 在三面板分别比较：

1. 静态CCC/训练窗均值；
2. last-value与现有双速EWMA；
3. Fisher-\(z\) AR(1)；
4. 共享系数的日—周—月HAR；
5. 其后才加入稳健cDCC/HMM。

所有阈值、长期中枢、状态持续期均只在训练折确定；预测窗重叠时至少embargo \(h-1\)，并用非重叠评估或时间块bootstrap。除pair CRPS外，矩阵另报相关部分Frobenius、PSD投影率；协方差QLIKE必须与“纯相关损失”分开，防止把可预测的波动率误算成相关预测能力。

**现有数据能否验证：** 加密1d四年足以验证低参数AR/HAR及7/22日分布预测，但危机转折次数仍少；美股1d仅数月，不满足 \(T_{\mathrm{eff}}\ge400\)，只做nowcast。1h面板可做初步滚动检验，但共同RTH样本、有效样本数和独立状态切换数决定结论，不能以37维原始bar数量替代。COR3M最多作为美股块的外生压力变量；它不覆盖加密、黄金、原油pair，当前也缺少相应期权数据链。

## 三、反方与陷阱

- 滚动相关的P90噪声约0.29，短窗“转折”很可能只是估计误差；长窗则必然延迟。
- 24/7币与RTH股票必须在共同RTH评价；异步交易和Epps效应会制造假脱耦。
- 逐pair预测不保证整矩阵PSD；投影后的预测必须重新评分。
- HMM只能使用实时filtered probability；smoothed state使用了未来信息。
- 高相关后的回落可能是窗口机械出样、风险溢价或结构中枢变化，不能自动解释为可交易均值回复。
- 多数论文预测完整协方差或组合风险；不能把其全部改善归功于相关性。

## 四、优先级

1. **P0，小改动，立即做：** 增加严格未来相关目标、CCC/last/EWMA基准、pair及块级CRPS/RPS账本。加密可完整验证；美股仅登记nowcast。
2. **P1，中改动：** 上线共享系数HAR及残差时间块bootstrap分布；仅当相对双速EWMA的CRPS skill在多个锁箱段为正、校准合格，才标记为“预测”。
3. **P2，中高改动，后置：** 稳健cDCC和filtered-HMM。需满足有效样本约束，并积累足够真实转折；否则只作为研究分支。
4. **P3，大改动，暂缓：** 自建期权隐含相关。先将COR3M作为美股块辅助特征，绝不直接替代物理相关预测。

最终划界：**相关水平与状态概率可以进入CRPS/RPS预测层；当前耦合及突变属于nowcast；精确脱耦时点目前只能作为实验性hazard输出。**
