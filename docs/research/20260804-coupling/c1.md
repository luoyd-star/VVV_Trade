# 主题C1：耦合/脱耦的操作化定义谱系

下列文献均经本轮网页核实，未使用【凭记忆】引用。

## 一、文献地图

首先必须区分两个概念：**低依赖是“脱耦状态”**；依赖从高到低发生显著、持续且具有经济量级的变化，才是“脱耦事件”。普通双侧断点检验只能证明“变了”，不能证明向下脱耦。

| 定义 | 检验对象与典型零假设 | “脱耦”实际含义 |
|---|---|---|
| 相关水平/断点 | 同步、标准化收益的 \(\rho_{ij,t}\)。\(H_0:\rho_t\) 恒定；Wied 等以 CUSUM 检测未知时点变化。【已核实】[Wied–Krämer–Dehling](https://doi.org/10.1017/S0266466611000661) | 低且稳定的 \(\rho\) 是状态；只有 \(\rho_{post}<\rho_{pre}-\delta\) 才是事件。若基准为负，应比较依赖强度而非简单“相关下降”。 |
| Beta 不稳定 | \(r_i=\alpha+\beta_{i\leftarrow j}r_j+\epsilon\)，\(H_0:\beta\) 恒定；未知断点可用 sup-Wald/LM/LR。【已核实】[Andrews（1993）](https://cowles.yale.edu/sites/default/files/2022-08/d0943.pdf) | 是基准资产暴露或对冲比率改变，不是因果关系消失。因 \(\beta=\rho\sigma_i/\sigma_j\)，波动率比变化可令 beta 变而相关不变。 |
| 协整破裂 | 各价格为 \(I(1)\)，但存在 \(b'p_t\sim I(0)\)，表示长期共同趋势约束。【已核实】[Engle–Granger](https://doi.org/10.2307/1913236) | 向量换挡但分段仍协整，与协整秩降为零不同。针对末端破裂可设 \(H_0\)：训练期与末端均维持协整。【已核实】[Andrews–Kim](https://doi.org/10.1198/073500106000000297) |
| 共同因子载荷消失 | \(r_t=\Lambda_t f_t+e_t\)，\(H_0:\Lambda_t\) 稳定。【已核实】[Han–Inoue](https://doi.org/10.1017/S0266466614000486) | 某资产或某块对共同因子的载荷/共同方差占比下降。载荷旋转、因子方差变化和因子数误设均会混淆解释。 |
| Copula/尾依赖变化 | \(\lambda_L=\lim_{u\downarrow0}C(u,u)/u\)，\(\lambda_U=\lim_{u\uparrow1}[1-2u+C(u,u)]/(1-u)\)；\(H_0\) 可为 copula 或 \(\lambda\) 恒定。【已核实】[Patton](https://public.econ.duke.edu/~ap172/Patton_IER_2006.pdf)、[Bücher–Ruppert](https://arxiv.org/abs/1206.1675) | 收益下尾 \(\lambda_L\) 下降才是“危机共跌脱耦”；\(\lambda=0\) 仅表示渐近尾独立，不等于总体独立。 |

这些定义互不等价：收益相关度量短期对称线性共动；beta 是选定基准后的非因果暴露；协整约束价格长期路径；因子载荷属于面板共同成分；copula 还包含非线性与上下尾不对称。高相关甚至可与渐近尾独立并存，零 Pearson 相关也可存在确定性依赖。

层级上：

- **Pair 级**：“A 与 B 脱耦”是指定统计量 \(\theta_{AB}\) 的下降或独立命题。
- **块级**：对象变为随机向量 \(X_A,X_B\)。线性命题为 \(H_0:\Sigma_{AB}=0\)；总体独立则是更强的 \(H_0:X_A\perp X_B\)，可用 distance covariance。【已核实】[Székely–Rizzo–Bakirov](https://doi.org/10.1214/009053607000000505)
- **全市场级**：指市场共同模态减弱或结构碎片化，不是“所有 pair 同时降相关”。所有 pair 独立甚至也不必推出高维联合独立。

宏观文献口径明显更宽。Kose–Otrok–Prasad 用106国动态因子，将“脱耦”定义为全球因子方差贡献下降，同时工业国和新兴市场各自组内因子增强；对象是产出、消费、投资，不是交易 pair。【已核实】[NBER w14292](https://www.nber.org/papers/w14292) Dooley–Hutchison则发现新兴市场在2007年至2008年夏看似隔离，雷曼后迅速再耦合，说明短暂背离不是结构脱耦。【已核实】[NBER w15120](https://www.nber.org/papers/w15120)

加密文献也呈明显时变性：早期样本中加密对传统股票和宏观因子暴露大多不显著，【已核实】[Liu–Tsyvinski](https://www.nber.org/papers/w24877)；IMF随后以同期相关及 VAR-X 预测误差方差分解发现2020—2021年加密—股票双向溢出显著增加。【已核实】[IMF 2022](https://www.imf.org/-/media/files/publications/gfs-notes/2022/english/gfsnea2022001.pdf) 后者的“方向”来自 VAR，不来自相关本身。

## 二、对 VVV_Trade 的操作化启示

建议保留现有五状态机，新增独立的 `coupling sidecar`，按三级输出：

| 层级 | 主统计量 | 零假设与判定 |
|---|---|---|
| Pair | 设基准方向 \(s_{ij}=\operatorname{sign}(\rho^{slow}_{ij})\)，定义 \(c_{ij}=s_{ij}\rho_{ij}\)；另报 beta、收益下尾共超越率 | 断点 \(H_0:c^{fast}=c^{slow}\)；生产判定采用更严格的 \(H_0:c^{fast}\ge c^{slow}-\delta\)。只有单侧显著下降、持续至少一个 fast 有效半衰期才记脱耦；符号翻转记“关系反转”。 |
| 块 \(A,B\) | \(E_{AB}=\|R_{AB}\|_F/\sqrt{n_An_B}\)，同时报有符号均值；Ledoit–Wolf 正则化 CCA 仅作最强通道审计 | \(H_0:R_{AB}^{fast}=R_{AB}^{slow}\)；绝对无线性耦合为 \(H_0:R_{AB}=0\)。若跨块能量下降但块内稳定，才称 A–B 脱耦；块内也下降则称全局碎片化。 |
| 全场 | \(m=\lambda_1(R)/N\)；跨块能量占比 \(b=2\sum_{A<B}\|R_{AB}\|_F^2/\|R-I\|_F^2\) | \(H_0:(m,b)\) 稳定。二者均显著下降为全市场脱耦；仅 \(b\) 下降而块内增强，是“组内再耦合、组间脱耦”。 |

实施约束：

- 三套面板分别计算；37资产全场指标只能使用共同 RTH 小时，不能把24/7收盘与美股休市价格拼接。
- \(\delta\) 必须由保留自相关、波动簇和缺失时钟的块 bootstrap 得到。当前同一60日设定下，阈值不应低于已测 \(P90|\Delta\rho|\approx0.29\)；其他频率重新校准。
- 严守 \(T_{\rm eff}\ge\max(10N,400)\)。现有数据可优先验证加密1d和满足400有效小时的共同RTH 1h；美股4h/1d历史不足。
- \(T_{\rm eff}=400,q=5\%\) 仅约20个边际尾样本，尾依赖只能作为探索项。协整先限于有经济锚、长历史的 pair。
- 预测阶段预测未来 \(c,E,m,b\) 的分布及状态概率，用 CRPS/Brier 和锁箱未来窗评分；不得把相关预测解释为“谁领先谁”。

## 三、反方与陷阱

- 危机期方差上升会机械改变未修正相关，经典“传染”结论经修正后可能消失。【已核实】[Forbes–Rigobon](https://www.nber.org/papers/w7267)
- 非同步收盘通常低估跨市场相关，甚至改变条件相关符号；这正支持共同RTH面板设计。【已核实】[Martens–Poon](https://doi.org/10.1016/S0378-4266(00)00159-X)
- 37资产产生666个 pair；滚动窗又高度重叠。单窗 \(p<0.05\) 必须让位于块 bootstrap、层级门控和 FDR。
- CCA是样本内最大化统计，小样本会严重上偏；因子载荷还存在旋转识别。
- “未拒绝无协整”不是证明脱耦；尾独立也不表示有限的5%或10%危机阈值下没有共跌。

## 四、优先级

- **P0／小改动**：实现 pair 的方向固定相关分数、块能量、全场 \(m,b\)，写入现有账本；先跑同步时钟与 \(T_{\rm eff}\) 资格检查。
- **P1／中改动**：建立匹配面板的块 bootstrap、最小效应量、持续性和层级 FDR；用严格未来窗比较“相关单指标”与“三级指标”预测增益。
- **P2／中大改动**：数据合格后再加入尾 copula、协整末端破裂和动态因子载荷检验。

结论分层：**共识**是脱耦必须说明对象、时间尺度、条件集与零假设；**争议**集中在阈值、copula/因子模型选择及小样本功效；**从业者建议**是以同步条件相关作为生产主轴，块级与全场级负责确认范围，beta、协整和尾依赖只作相互独立的诊断通道。
