# 主题1：相关性状态检测的方法学

## 一、文献与方法地图

1. 滚动窗/EWMA（学术共识）：不存在跨频率通用最优窗；短窗方差大、长窗会抹平结构变化。RiskMetrics 的日频 \(\lambda=0.94\) 只是行业基准，且明确指出更大的 \(\lambda\) 更平滑、未必更准确；不能直接移植到小时频率【已核实】([MSCI原文](https://www.msci.com/documents/10199/5915b101-4206-4ba0-aee2-3449d5c7e95a))。Marti 等发现短样本会产生伪聚类，厚尾下 Spearman 优于 Pearson，但其“250日”结果来自 \(N=265\) 的特定模拟，不能视为定律【已核实】([IJCAI论文](https://franknielsen.github.io/papers/ijcai-marti16.pdf))。

2. DCC-GARCH（有条件共识、增益有争议）：Engle 的两步估计令标量 DCC 可扩展到几十个资产【已核实】([Engle 2002](https://doi.org/10.1198/073500102288618487))；资产配置研究发现动态正确的相关预测平均有约60bp年化价值，但并非结构变点检验【已核实】([Engle–Colacito](https://doi.org/10.1198/073500106000000017))。反方是 Aielli 证明传统大系统 DCC 估计可能不一致，并提出 cDCC【已核实】([Aielli 2013](https://doi.org/10.1080/07350015.2013.771027))；一次性冲击下稳健 DCC 样本外优于标准 DCC【已核实】([Boudt等](https://doi.org/10.1016/j.ijforecast.2012.06.003))。故 DCC 应是挑战者而非默认方案。

3. RMT（大维度共识，小宇宙适用性有争议）：Laloux、Plerou 等在数百至上千股票中发现多数特征值接近随机矩阵谱，少数大特征值承载市场/行业信息【已核实】([Laloux等](https://arxiv.org/abs/cond-mat/9810255))。但 Marchenko–Pastur 是 \(N,T\to\infty,\ N/T\) 固定且近似独立同分布的渐近零模型；厚尾样本协方差可直接破坏 MP 定律【已核实】([Frahm–Jaekel](https://arxiv.org/abs/physics/0503007))，RMT 过滤也曾在高波动期增加样本外风险【已核实】([Daly等](https://doi.org/10.1016/j.physa.2008.02.045))。因此 \(N=13\) 不宜用 MP 硬切谱；\(\lambda_1/N\) 作为普通 PCA 同步化指标仍有价值。

4. 网络与聚类（解释性较强）：MST 用 \(d_{ij}=\sqrt{2(1-\rho_{ij})}\) 提取经济上可解释的层次骨架【已核实】([Mantegna](https://arxiv.org/abs/cond-mat/9802256))；PMFG 保留 \(3N-6\) 条边、包含 MST 并增加团结构【已核实】([Tumminello等](https://doi.org/10.1073/pnas.0500298102))。但边需要 bootstrap 可靠度【已核实】([Tumminello等](https://arxiv.org/abs/physics/0605116))。当前 \(N=13\) 时完整图仅78条边，MST丢失过多、PMFG仍保留33条，均不比完整矩阵和层次聚类更自然。

5. 相关性 regime（无统一定义）：文献主要有三种操作化：滚动矩阵聚类形成“准稳定市场状态”【已核实】([Münnix等](https://doi.org/10.1038/srep00644))；平均相关、离散度或首特征值阈值；以及两侧矩阵 Frobenius 差异加 bootstrap 的直接变点【已核实】([Barnett–Onnela](https://pmc.ncbi.nlm.nih.gov/articles/PMC4703970/))。前两者适合在线监控，第三种更接近“结构确实改变”的统计定义。

## 二、对 VVV_Trade 的具体启示

1. 数据与窗口层（改动小）。依据是美股永续盘外价格近乎停滞，ET 去季节化仍不能制造有效信息；直接与24/7加密同步会压低或扭曲相关。建议维护“加密24/7面板”和“股币共同RTH面板”，固定资产成员、共同时间支持，禁止逐对缺失删除。窗长采用工程网格而非宣称最优：加密1h为168/720/2160、4h为42/180/540；RTH 1h为130/390/780个有效bar、4h为90/180/360；1d为60/120/252。快速窗只预警，状态需中慢窗确认。硬门槛建议 \(T_{\rm eff}/N\ge5\)，优先大于10；扩至50品种时不足者自动进入 shadow。EWMA 用半衰期 \(h\) 定义，\(\lambda=2^{-1/h}\)，不可把0.94逐bar复用。现有数据：加密三频可验证；美股1h有限可验证，4h仅部分窗，1d尚不足稳健锁箱。

2. 推荐最小可行组合（改动中）：对时段标准化收益建立快/慢两套“EWMA协方差＋线性收缩后相关矩阵”；主状态量取平均非对角相关、相关离散度、\(\lambda_1/N\)。再回归剥离第一PC，计算残差矩阵的归一化 Frobenius 漂移，并以 Spearman 层次聚类的 ARI/成员迁移定位主题重组。同步态定义为平均相关与首特征值持续越过因果分位数；结构旋转定义为残差矩阵距离超过块bootstrap零分布且聚类稳定性显著下降。它应作为现有5状态机的正交 `corr_state/rotation_event`，避免扩成状态笛卡尔积。

3. 主题方向不能由相关性推出。相关网络只能说明“谁与谁重新同动”；“AI基建→AI应用”还需冻结主题成员后，用市场模式残差收益、相对成交量/VWAP共同确认流出组为负、流入组为正（改动中；现有1h数据可做）。SOXL与半导体股、QQQ与其成分存在机械重叠，应单列为派生暴露，不能把高相关解释成资金迁移。

4. 实验设计（改动中）：在 crypto4、equity9、all13 固定面板上做嵌套 walk-forward；内层选择窗口、半衰期和收缩强度，锁箱只评一次。基线为慢窗常相关、滚动＋Ledoit–Wolf、EWMA；挑战者为 cDCC/GARCH-t。评估未来矩阵 Frobenius/高斯负对数分数、跨窗方向一致率、聚类 churn、误报/千bar、检测延迟及运行时间。因美股历史缺少足够真实制度切换，应对完整多变量行做 stationary block bootstrap，并注入已知因子载荷旋转，测功效和定位误差；全部进入现有 trial ledger。

## 三、反方与陷阱

- 许多“动态相关”可能是抽样误差或结构断点造成的伪动态，研究中滚动窗有时反而优于 DCC【已核实】([Adams等](https://doi.org/10.1016/j.jbankfin.2017.07.003))。
- 高波动条件抽样可机械抬高相关；经典危机研究在调整异方差后，多数“传染”证据消失【已核实】([Forbes–Rigobon](https://www.nber.org/papers/w7267))。应先做时段波动标准化。
- 相邻滚动矩阵共享 \(W-1\) 个观测，天然产生平滑和假持续；显著性必须用保留横截面的块bootstrap，不能把每个bar当独立样本。
- 平均相关与 \(\lambda_1/N\) 在近等相关市场中高度重复；特征向量又有符号任意和近重根换位问题。旋转应比较 \(VV^\top\) 的子空间距离，并要求 eigengap/bootstrap 支持。
- MST 边会因接近并列的相关发生离散翻转；固定成员变化、上市缺口、盘外静价也都会伪造拓扑漂移。网络图只作解释层，不作唯一触发器。
- \(N=13\) 的主题块过小，且当前美股历史只覆盖有限市场环境；漂亮的历史聚类不能等同可交易轮动。

## 四、优先级（本主题内最值得先做的 1-2 件事）

1. 先做共同RTH/24×7双面板、双速收缩EWMA及三项全局状态量；这是 \(N≈20\!-\!50,\ T≈数百\!-\!数千\) 下最稳定、最便宜的基线。
2. 再加市场模式残差矩阵变点＋bootstrap层次聚类，并让 cDCC、MST、MP过滤在同一锁箱中竞争；未显著改善误报—延迟曲线前不进入生产。
