# 路线8：端到端数值对拍（历史上产出真 P0 最多的路线）
挑 6 个品种（覆盖不同 regime：range/trend_up/trend_down/squeeze/high_vol_chop + 1 个数据不足的），
对每个品种把**同一个数字**从库出发追到每个出口，验证全链一致：
库内 OHLCV → extract_levels 的 zone → locate 的 at/role/dist_atr → overview payload
→ 主页卡片文案 → 详情页政策卡 → Hermes <panel> 文本。
重点验：
1. 同一个 zone 在主页与详情页显示的 lo/hi/touches 是否一致？
2. dist_atr 的计算：区间内=0、区间外=到最近边界的 ATR 距离——各出口是否同口径？
3. cRSI 读数在详情页(现有 crsi 卡)与政策卡是否同源同值？
4. play 文案在主页/详情页/Hermes 三处是否一字不差？
5. 波动率标注的数字（IV3/分位/预期波动）与详情页 IV 卡是否一致？
任何一处不一致都是 P0——用户会同时看到两个数字。
