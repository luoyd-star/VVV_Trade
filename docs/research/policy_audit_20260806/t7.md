# 路线7：Hermes 集成（单品种 + 横截面双模）
1. render_overview_context 注入的横截面内容：字段是否齐全、口径是否与面板一致？
   token 量估算（会不会撑爆上下文）？
2. scope=overview 与单品种模式的切换：chat 表共享同一条对话流，
   模型能否分清"上一轮问的是总览、这一轮问的是单品种"？scope 是否随消息记录？
3. **时间感知**：本系统刚加了时间感知三件套（当前时刻锚点/历史消息时间前缀/时间跳变横幅）。
   验证在 overview 模式下这三件套是否仍然生效。
4. PANEL_LEGEND 是否补了总览字段说明？有没有字段被注入却没解释（模型拿到数字不知含义）？
5. Hermes 会不会把 policy 的"建议关注"升级成"应该买入"？提示词里有没有防线？
6. 单品种 <panel> 里现在有没有 policy 块？如果有，与总览注入是否重复/矛盾？
