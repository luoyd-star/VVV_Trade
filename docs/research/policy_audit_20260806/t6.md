# 路线6：前端两页（overview + 详情页）
1. **信息架构**：主页分层（机会卡片/接近行/风险行/观望折叠/不可用折叠）是否符合
   "WAIT 是常态"的哲学？有没有诱导用户找事做的设计（秒表、红点、催促文案）？
2. **文案审查**：全部用户可见中文，逐条查有没有指令式措辞（"买入""做空""立即"）。
   系统不下单，只能"建议关注"。
3. 详情页政策卡：关键位表是否给出了足够的依据（距离/来源/触碰/角色/eligible）？
   不 eligible 的行是否说明了原因？
4. 两页的状态色、字号、术语是否与既有 style.css 体系一致？有没有新造的口径词？
5. XSS：所有服务端字符串进 innerHTML 前是否都过了 esc()？新代码有没有遗漏？
6. 主页与详情页的深链（/symbol?symbol=XXX）是否正确？非法参数怎么处理？
7. 心跳条在主页是否正常复用？
