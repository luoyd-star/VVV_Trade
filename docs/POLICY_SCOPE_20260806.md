# Policy 分期边界（2026-08-06）

本表以仓库根目录 `eric-policy.md` v2026-07-11 为唯一规格边界。“已实现”仅表示本期交付的**测量与展示输入**，不表示系统已经实现交易决策、下单或仓位指令。系统始终只给建议与理由。

## 章节边界

| 规格章节 | 本期状态 | 边界与理由 |
|---|---|---|
| §0 接口契约 | 本期已实现（部分） | 输出关键位、位置、1h cRSI、结构止损宽度、IV/财报风险与降级原因；账户、持仓、建仓状态、情绪标志不在本期。 |
| §1 Regime 映射 | 本期不做（属前序状态层） | 复用现有 `classify.py` 的五态近似映射；本期铁律禁止修改分类器。 |
| §2 核心政策矩阵 | 本期已实现（仅位置/信号测量） | 只展示可匹配剧本与未过门槛；不输出 `OPEN_*`、`CLOSE`、`MANAGE` 等动作。逐剧本边界见下表。 |
| §3 开仓前置门槛 | 本期已实现（GATE 1 测量的一部分） | 可找结构失效位并与实际期限 IV 比较；账户 1% 定仓、RR、完整共振计票、DCA 校验属后续决策期。 |
| §4 DCA vs 一把梭 | 本期不做（属决策/持仓期） | Hermes guard 仅保留 P21 否决边界；没有预算、子弹或加仓动作引擎。 |
| §5 持仓管理 | 本期不做（属持仓管理期） | 当前 payload 没有可靠 position 生命周期输入。 |
| §6 全局否决层 | 本期已实现（文本边界）/其余后续 | Hermes guard 落实 P20/P21 与 WAIT 常态；报复、踏空、流动性、异常环境等需决策状态后实现。 |
| §7 信号代理 | 本期已实现（超买/超卖一项） | 复用现有 1h cRSI 区域；背离、反转量、突破预警和共振计票不在本期。 |
| §8 长周期覆盖层 | 本期不做（属长周期/DCA 期） | 本期没有周线超卖事件状态、趋势年龄或 DCA 状态机。 |
| §9 保真度声明 | 本期已实现（展示） | policy 卡下发 `lv1/loc1/stop1/vol1`，明确“先验、未校准”；不声称胜率。 |

| S2 拐头结构前低反弹 | 本期不做（属期2） | 当前 regime 集没有独立 `turning_unconfirmed` 决策入口，也未实现底背离。 |
| S3 区间边沿交易 | 本期已实现（测量参考） | 可测 range 上/下沿与 cRSI；固定 R、机械退出属决策期。 |
| S4 上升趋势回踩 | 本期已实现（测量参考） | 可测 EMA21/55 或结构低点回踩、来向与超卖。 |
| S5 突破回踩加仓 | 本期已实现（测量参考） | 可识别旧压力翻转支撑；“加仓”仅是剧本名，不输出仓位指令。 |

| S16 情绪满仓否决 | 本期已实现（Hermes 文本边界） | guard 否决满仓/一把梭并改为讨论 DCA；自动文本分类与建仓状态机后续实现。 |

## 明确不在本期的系统能力

- 决策引擎、自动下单、命令式开平仓、账户百分比仓位。
- 背离分级、反转爆量、突破预警、完整 confluence 计票。
- position 生命周期、目标/RR、Route A/B、DCA 子弹状态。
- 参数校准、收益归因和胜率声明。
