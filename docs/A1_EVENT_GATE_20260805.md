# A1 事件感知确认门槛：诊断 → v3 升版 → 回测（2026-08-05）

用户批准实施（调研判决 A1 项）。全程遵守"先诊断定强度、测量层不动、版本谓词重算"。

## 一、实施前诊断（决定门槛形态与强度）

**假说**（来自调研）：压缩态 + 财报窗 ≤10 日 → 扩张概率 60.6% vs 21.4%（2.83×），
事件驱动的扩张多为双向脉冲而非趋势诞生 → 事件窗内从 squeeze 确认趋势应更谨慎。

**本地检验**（v2 确认态历史，61 美股 × 1h/4h/1d，约 5 个月 ≈2 个财报周期）：

| tf | 组 | 转换数 | 10 根内失败率 | 真趋势率(拿住≥10根) |
|---|---|---|---|---|
| 1h | 事件窗内 | 37 | **83.8%** | **16.2%** |
| 1h | 窗外 | 285 | 77.2% | 22.8% |
| 4h | 事件窗内 | 10 | **80.0%** | 20.0% |
| 4h | 窗外 | 61 | 72.1% | 27.9% |

方向与假说一致（1h/4h 皆同向），但 **z≈0.9 未达显著**（窗内样本 n=37）。
退出去向分布（窗内外都是 ~72% 回 range）无显著差异；"脉冲签名"未见富集。

**诊断决定**：门槛取**最小可辩护强度 +1 根**（2→3），只作用于
"事件窗内 squeeze→trend_up/trend_down"这一种转换。依据 = 外部实证（2.83×）
+ 本地方向一致 + 机制清楚（IV crush 脉冲），但本地未显著 → 不允许更强的干预。
**预登记复评**：窗内转换样本 ≥100 时（约再 3-4 个财报季）由每周复跑重估；
若届时失败率差消失，v4 撤销此门槛。

## 二、实现（RULES_VERSION v2 → v3）

- **测量层 `classify()` 零改动**——事件不改变波动率是多少，改变的是同样的读数
  对未来意味着什么，故只动确认层（`confirm_states`）。
- `_confirm_need(state, from_state, event_win)`：仅 `event_win ∧ from==squeeze ∧
  to∈{trend_up,trend_down}` 时 need 2→3。冲击态（high_vol_chop）永远 1 根不变。
- `storage.earnings_event_windows()`：逐 bar 判"未来 10 日历日内有财报"。
  **point-in-time 先验留痕**：对 ≤10 日前瞻窗，财报日期在 t 时刻已知是极强先验
  （日期提前数周公布）；known_at 对新行有效，历史回填行不按其过滤——记录在案，
  将来严格 as-of 收紧点只在此一处。
- collector 与面板两条确认路径**同参接线**（不同参会出现"显示 2/2 却不切"）。
- 无财报数据的品种（加密/商品/ETF）`event_win=None`，行为与 v2 逐位一致。
- 候选展示：面板"（事件窗·门槛+1）"、Hermes 附完整解释、candidate 带 event_win 键。

## 三、升版回测（全量重算 + v2/v3 差分）

重算 236,379 行（24.8 分钟）。差分（对 v2 快照 236,305 行）：

| 检验 | 结果 |
|---|---|
| **原始态差异** | **0 行** ——测量层零变化的硬检验通过 |
| 确认态差异 | 102 行（0.043%），**全部**为 trend→squeeze（门槛拦下的那一种），无泄漏 |
| 品种/周期边界 | 25 个美股品种、仅 1h/4h；**非美股混入 0** |

**干预质量**（48 个 episode，逐个追溯 v2 世界里的下场）：

| | 次数 | 占比 |
|---|---|---|
| 好拦截（v2 该趋势 10 根内失败——门槛避免了假信号） | **39** | **81%** |
| 坏拦截（v2 该趋势拿住 ≥10 根——真信号被延迟） | 9 | 19% |
| 其中：v3 延迟 1 根后仍确认 | 30 | |
| 其中：v3 彻底未确认 | 18 | |

**诚实解读**：81% 好拦截率要对照基础率看——窗内转换本来就有 ~84% 失败率，
门槛的边际改善是温和的（与诊断的不显著一致）。它的真实价值主张是：
干预面极窄（5 个月 61 品种仅 48 次）、代价极低（真信号最多迟 1 根）、
方向有外部强证据支撑，且**完全可逆**（复评不利即 v4 撤销）。

## 四、版本纪律

- v3 与 v2 的确认态历史**不可比处仅限上述 102 行**；回测按版本谓词自动隔离。
- 阈值登记：EVENT_WINDOW=10 日历日、GATE=+1 根、适用转换=squeeze→trend——
  三者均为版本化先验，修改须新版本号。
