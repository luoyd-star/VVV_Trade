# 耦合/脱耦系统设计规格 · 2026-08-04

跨品种相关的**计算-识别-判断-预测**四段操作化。综合 8 路 codex 调研
（[research/20260804-coupling/](research/20260804-coupling/)）+ 监工核查（抽 6 条引用全实，
两轮编队累计零幻觉）。落在预研四层架构（PRERESEARCH_XASSET）之上，本文是 L0-L3 的施工级细化。

## 0. 两个统领性区分（C1/C2，全文的语法）

- **状态 vs 事件**：低依赖是"脱耦状态"；依赖发生显著、持续、有经济量级的**下降**才是"脱耦事件"。
  普通双侧断点检验只证明"变了"——生产判定一律用单侧 H0: c_fast ≥ c_slow − δ。
- **预测边界**（诚实划界）：相关**水平**与**状态概率**可进预测层（CRPS/RPS 验证）；当前结构与突变
  是 **nowcast**；精确脱耦**时点**只能作实验性 hazard，因果**方向**永不进正式输出。
  文献底数：HAR-DRD 持续性权重 0.77-0.89（有可预测性）但 EWMA 经常不输复杂模型
  （Romero-Opschoor 2026 JAE，计入换手后更强）——**双速 EWMA 是必须先被打败的基准**。

## 1. 计算层（L0 细化）

- 三面板（加密 24/7 / 美股 RTH / 跨类共同 RTH）+ 时段波动标准化 + Ledoit-Wolf。
  共同 RTH = calendar_nyse.bar_full_rth 的 6 根完整小时（早收日 3 根），滞后在日界重置。
- **一切相关统计在 Fisher-z 域**（atanh ρ）计算与建模，输出时还原。
- 双速 EWMA：**半衰期 140 / 420 共同小时**（T_eff≈404/1212，满足 ≥max(10N,400)）。
  数据不足输出 `INSUFFICIENT`，禁止缩窗冒充。
- Pair 主量：方向固定相关分 c_ij = sign(ρ_slow)·ρ_ij；另存 β_ret（收益暴露）与
  β_spread（对冲比）——**二者永不混用**（β=ρσi/σj，波动比变化可令 β 变而 ρ 不变）。
- 块级：跨块能量 E_AB = ‖R_AB‖F/√(nA·nB)（带符号均值另存）；主题直读量 D_b = 块内均值 a_b − 块外 e_b。
- 全场：市场模式 m=λ1/N + 跨块能量占比 b。原始/波动标准化/因子残差三口径**并报**
  （Forbes-Rigobon：异方差会伪造"传染"；剥 PC1 会删真实危机共振——都不可只看其一）。

## 2. 识别层：pair 四态状态机（C6 参数表，全部先验待校准）

**资格门**：|ρ_slow|≥0.25 且参考期同号率≥80% 且覆盖率≥95%——弱相关 pair 是"不适用"，不是"已脱耦"。

状态量 x = s·atanh(ρ_fast)；episode 锚 z_A 冻结于进入时，d = s(z_A − z_fast)/σ_d。
阈值 L=q10%(x)、H=q30%(x)（因果分位），效应门 δ* = 零模型 P90|Δρ|（60d 版本地板 0.29）。

| 转移 | 条件（pair） | 块级（breadth = 报警 pair 占比） |
|---|---|---|
| coupled→decoupling | x<H 且 d≥2 且 Δρ≥δ*，连续 2 bar | 块跌幅≥1.5σ 且 breadth≥30%，连续 2 |
| decoupling→decoupled | x≤L，连续 3 bar | breadth≥40%，连续 2 |
| decoupled→recoupling | x>L 且 d 自峰值回落≥0.75，连续 2 | breadth 恢复≥30% |
| recoupling→coupled | x≥H 且 d≤0.75，连续 3 bar | 恶化 breadth≤20%，连续 3 |
| 驻留下限 | decoupled≥5 bar，其余≥2 | ≥3 bar |
| 技术态 | 活动期超 2T_F → REBASE_PENDING（不许自动洗成 coupled） | 同 |

符号翻转单列"关系反转"，不占用脱耦语义。块级另配 C4 五统计量
（m / 全局残差 omnibus T_G / D_b / 社区共识 ARI+迁移矩阵 / 子空间角 d_sub 带 eigengap 资格），
显著性 **global-first**：先过 T_G 的块 bootstrap 全局门，再下钻到块与 pair（max-stat/FDR），
杜绝 666 对 pair 的逐边显著性灾难。块状态采用 **三票制**（跨块 Fisher-z 中位 / 两块 PC1 相关 /
显著边密度，至少两票同意才切换）。

**判定四分类语义**（C4）：仅 m 变=全局再耦合；D_b 变而 ARI/d_sub 稳=**强度型脱耦**；
D_b+迁移+有 gap 支持的 d_sub 同变=**拓扑重构**；角度未超零带或 eigengap 不足=**不可辨识**（如实输出）。

## 3. 判断层：语境与协变量（C8）

- pair 脱耦+块耦合=特异性断裂；pair+块同脱=系统性断裂；pair 耦合+块脱=相对韧性。
- 币股耦合 episode 底数（先验）：2017-19 ρ≈0.02 → 2020 疫情 0.42-0.56 → 2022 紧缩 0.69-0.80 →
  2023 回落 0.30 → 2024 ETF 窗口≈0（事件脱耦）→ 2025 再耦合 0.48 → 2026Q2 相对收益脱耦。
  规律：**压力期高耦合、加密特有事件期可脱耦**；BTC 不是避险资产（2022 金 −7%/BTC −70%）。
- 协变量清单（判断层输入，FRED 免费为主）：DFII10 实际利率、广义美元、NFCI、HY OAS、VIX、
  稳定币供给、ETF 净流、CME OI 占比、funding/强平异常。规则先验进**概率**不进硬覆盖：
  宏观三高（实际利率/美元/信用利差）+资金撤出 → 提高"risk-off 耦合"概率；加密链上/交易所
  事件而股票安静 → "加密特有脱耦"；AI 财报冲击而 crypto 安静 → "股票特有脱耦"。
- XAU：**条件性**避险先验（股票尾部下跌且金自身无流动性抛售时才赋），不设固定负 beta；
  CL：先判需求 vs 地缘冲击再判相关符号（Kilian-Park）。
- MSTR/COIN：高 beta 成立（MSTR≈1.37 且受 mNAV/发行稀释调制），"COIN 稳定领先 BTC"无据。

## 4. 预测层（C2）

- 目标：ρF_{ij,t,h} = Corr(r_{t+1:t+h})（Fisher-z 域分布预测，CRPS）；块级固定权重均值 z（主）
  与 λ1 占比（副）；四态转移概率（多类 Brier，循环状态不强行排序）。
- 未来窗预注册：1h {1,6,24}、4h {1,6,30}、1d {1,5,20} eligible bars；重叠 embargo h−1。
- 基准阶梯（挑战者必须逐级击败）：状态延续 → last-value → 双速 EWMA → Fisher-z AR(1) →
  共享系数 HAR；其后才准入稳健 cDCC / filtered-HMM（smoothed 状态=用未来，禁止）。
- COR3M 只作美股块外生压力变量（风险中性≠物理预测，且不覆盖加密/商品）。

## 5. 校准协议（C6，上线前硬门）

- 对整条 N 维收益向量做 stationary block bootstrap（≥20,000 条路径），每条重跑标准化→收缩→
  双速 EWMA→完整状态机；按一个 panel-年 的 H 校准：每 pair P0(误入 decoupled≤H)≤5%（横截面 FDR 10%），
  整 panel 任一块误入≤5%；注入 Δρ∈{0.15, 0.29, 0.40}，可检档要求 P(延迟≤0.25·T_F)≥80%。
- 报告完整运行长度分布（均值 ARL 不够：ARL0=500 时 100 步内误报仍约 18%）。
- 事件研究对照：risk-set matching（同期未发病 pair 按面板/状态/波动/流动性配对），
  共享资产与重叠窗合并为 inference block；**≥30 个独立 block 且锁箱 ΔCRPS 为正**才允许
  进入五状态机的正式决策路径，此前只作诊断输出。

## 6. 使用边界（C7 成绩单）

组合 VaR/ES 条件化 **B+** / 风险预算 **B−** / 个券方向 **C** / 危机预警 **C−**。
- **第一实验（P0，改动最小证据最强）**："只换相关、边际不变"的 VaR/ES 归因——分离相关预测的
  真实贡献（文献：高频模型 QLIKE 改善 26.5% 中相关只占 1.8pt，勿高估）。
- 生产融合：R_t = (1−q_t)R_slow + q_t·R_fast，q 来自置信度；**非对称覆盖**：高耦合只许降险，
  表观脱耦永不加杠杆；脱耦触发对冲**退出/禁入**，不触发均值回归加仓（Clegg：协整无跨期持久性）。
- 永不声明清单：谁带动谁的因果、主题间"价格发现份额"、显著方向即可交易、脱耦必回归、
  重叠窗连续显著=多次独立证据。
